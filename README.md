# ☕ پارس کافی (parsCoffee)

وب‌سایت تعاملی و مدرن فروشگاه تخصصی دانه‌های قهوه با انیمیشن‌های مبتنی بر اسکرول (Scroll-Driven Experience) و همگام‌سازی فریم‌های ویدیوی دم‌آوری قهوه.

---

## ✨ ویژگی‌های کلیدی

- 🎬 **پیمایش فریم به فریم ویدیو با اسکرول (Scroll-Driven Video):** هماهنگی کامل زمان ویدیوی پس‌زمینه با اسکرول کاربر با تکنیک Lerp Interpolation.
- 🌊 **اسکرول بی‌نهایت روان (Smooth Scroll):** استفاده از کتابخانه پرقدرت **Lenis** برای ایجاد حس یک وب‌اپلیکیشن فوق لوکس.
- 🪄 **انیمیشن‌های سینمایی با GSAP:** ورود و خروج متنوع المان‌ها (Fade-up, Slide, Stagger) همراه با پلاگین **ScrollTrigger**.
- ☕ **نمایش محصولات با افکت انعکاس آینه‌ای (Floor Reflection):** طراحی پاکت‌های اختصاصی قهوه با جزئیات دقیق و انعکاس روی سطح صیقلی.
- 🔢 **شمارنده‌های آماری تعاملی:** انیمیشن شمارش اعداد به صورت فارسی در بخش استانداردهای قهوه.
- 🛒 **سبد خرید تعاملی و اعلان‌ها (Toast Notifications):** امکان افزودن دانه‌ها به سبد خرید همراه با به‌روزرسانی شمارنده و نوتیفیکیشن اختصاصی.
- 📱 **طراحی کاملاً واکنش‌گرا (Responsive & RTL):** سازگار با تبلت، موبایل و دسکتاپ به همراه فونت چشم‌نواز **وزیرمتن (Vazirmatn)**.

---

## 🛠️ تکنولوژی‌های استفاده‌شده

- **HTML5 & CSS3**
- **Tailwind CSS** (استایل‌دهی سریع و مدرن)
- **Vanilla JavaScript (ES6+)**
- **GSAP 3 & ScrollTrigger**
- **Lenis Smooth Scroll**
- **فونت فارسی وزیرمتن (Vazirmatn)**

---

## 🚀 نحوه اجرا

این پروژه کاملاً ایزوله و بدون نیاز به بیلد تولزهای سنگین یا `npm install` طراحی شده است:

1. ریپازیتوری را کلون یا دانلود کنید:
   ```bash
   git clone https://github.com/your-username/parsCoffee.git
   ```
2. وارد پوشه پروژه شوید.
3. فایل `index.html` را مستقیماً در مرورگر خود باز کنید یا با استفاده از **Live Server** (یا سرور محلی مثل `npx serve .`) اجرا نمایید.
